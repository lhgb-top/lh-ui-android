# Локальная линковка

## Соглашение о семейной раскладке

```
lh-ui/                        # родительский каталог семейства (не репозиторий)
├── lh-ui-core/               # источник токенов + codegen
├── lh-ui-android/            # этот репозиторий
├── lh-ui-ios/                # репозитории-братья
├── lh-ui-harmony/
└── lh-ui-windows/
```

Когда все репозитории лежат в одном родительском каталоге, токены **подключаются напрямую локально**; если репозиториев-братьев нет (CI клонирует один репозиторий), выполняется **автоматический откат на npm-пакет**.
Это эквивалентно механизму vite-alias с проверкой наличия в направлении web (генеральный план D18).

## Трёхуровневая проверка наличия

`scripts/link-tokens.mjs` ищет артефакты токенов в порядке приоритета:

| Приоритет | Источник | Описание |
| --- | --- | --- |
| 1 | `../lh-ui-core/dist/android` | Локальное подключение: изменение токенов применяется мгновенно |
| 2 | `node_modules/@lh-ui/core/dist/android` | Откат на npm: `files: ["dist"]` пакета `@lh-ui/core` содержит артефакты для четырёх платформ |
| 3 | — | Выход с ошибкой: без токенов сборка невозможна |

## Повседневный процесс

```bash
# 1. Изменить токены (в репозитории core)
cd ../lh-ui-core
vim tokens/color.json           # или spacing / typography / ...

# 2. Перегенерировать + проверить
pnpm codegen                    # генерирует артефакты dist/ для четырёх платформ
pnpm verify                     # schema + ссылки + контрастность WCAG + согласованность контрактов

# 3. Вернуться в этот репозиторий и синхронизировать
cd ../lh-ui-android
pnpm link:tokens                # перезаписывает core/src/main/kotlin/top/lhgb/ui/tokens/

# 4. Регрессия
./gradlew :components:button:test
```

## CI-гейт

```bash
pnpm link:tokens:check          # проверяет, синхронизированы ли токены (сравнение количества файлов; если нет — код выхода 1)
```

## Запрещённые действия

- ❌ Ручное редактирование `core/src/main/kotlin/top/lhgb/ui/tokens/` (генерируемое, gitignore)
- ❌ Коммит сгенерированных файлов токенов в репозиторий
- ❌ Цвета/интервалы литералами в компонентах (например `Color(0xFF2B4C7C)`, `16.dp`, `14.sp`)
- ❌ Запись зависимостей в форме `file:` / `link:` в `build.gradle.kts` и коммит (линковка только для локальной разработки)

## Устранение неполадок

| Симптом | Причина | Решение |
| --- | --- | --- |
| Ошибка компиляции `unresolved reference: LhTokens` | Токены не синхронизированы | `pnpm link:tokens` |
| Значение токена не соответствует ожидаемому | В репозитории core не был перезапущен codegen | Выполнить `pnpm codegen` в core и повторить линковку |
| `link:tokens` сообщает «артефакты токенов не найдены» | Репозиториев-братьев нет, а npm-пакет не установлен | Проверить семейную раскладку или `pnpm i -D @lh-ui/core` |
| Тёмные цвета неверны | Изменили светлый основной цвет, но не обновили предвычисленные тёмные значения | Обновить `color-dark.json` и перезапустить (R-n6) |
