features:
  - title: Token-driven
    details: Zero hardcoded colors or spacing in components. Everything consumes the LhTokens / LhDarkTokens generated by core codegen — change a token and it takes effect across the whole app instantly.
  - title: Spec-consistent
    details: Prop names align verbatim with lh-ui-core/specs, sharing behavior with iOS / HarmonyOS / Windows and the web bloodline.
  - title: Guarded by golden cases
    details: Behavioral assertions from cases/button.json are translated into JVM JUnit and Compose UI tests, so CI runs the same set of assertions.
  - title: Light and dark themes
    details: Switch with a single LhTheme call. Dark tokens are precomputed by core — no runtime color math, no flicker.
  - title: Chinese-style design language
    details: Blue-and-white porcelain primary, rice-paper white background, gamboge and cinnabar accents, a serif font stack — same source, same values as the web bloodline.
  - title: Native Compose
    details: "Hand-written UI in pure Kotlin + Compose: no JS runtime, no HTML/CSS bridging — declarative UI as a first-class citizen."
