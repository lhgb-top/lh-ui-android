# الربط المحلي

## اصطلاح تخطيط العائلة

```
lh-ui/                        # الدليل الأصلي للعائلة (ليس مستودعًا)
├── lh-ui-core/               # المصدر الأصلي للرموز + codegen
├── lh-ui-android/            # هذا المستودع
├── lh-ui-ios/                # مستودع شقيق
├── lh-ui-harmony/
└── lh-ui-windows/
```

عند وجود جميع المستودعات تحت نفس الدليل الأصلي، تُربط الرموز **محليًا مباشرة**؛ وعند عدم وجود المستودعات الشقيقة (استنساخ مستودع واحد في CI) يتم **الرجوع تلقائيًا إلى حزمة npm**.
وهذا يتطابق هيكليًا مع آلية حارس vite alias الخاصة بسلالة الويب (الخطة الرئيسية D18).

## حارس من ثلاث مستويات

يبحث `scripts/link-tokens.mjs` عن منتجات الرموز حسب الأولوية:

| الأولوية | المصدر | الشرح |
| --- | --- | --- |
| 1 | `../lh-ui-core/dist/android` | ربط محلي مباشر: تعديل الرموز ينعكس فورًا |
| 2 | `node_modules/@lh-ui/core/dist/android` | الرجوع إلى npm: حقل `files:["dist"]` الخاص بـ `@lh-ui/core` يحتوي على منتجات الأطراف الأربعة |
| 3 | — | الخروج بخطأ، غياب الرموز يمنع البناء |

## العمل اليومي

```bash
# 1. تعديل الرموز (في مستودع core)
cd ../lh-ui-core
vim tokens/color.json           # أو spacing / typography / ...

# 2. إعادة التوليد + التحقق
pnpm codegen                    # توليد منتجات dist/ للأطراف الأربعة
pnpm verify                     # schema + المراجع + تباين WCAG + اتساق العقد

# 3. العودة إلى هذا المستودع للمزامنة
cd ../lh-ui-android
pnpm link:tokens                # استبدال core/src/main/kotlin/top/lhgb/ui/tokens/

# 4. الانحدار
./gradlew :components:button:test
```

## بوابة CI

```bash
pnpm link:tokens:check          # التحقق من مزامنة الرموز (مقارنة عدد الملفات، إذا لم تكن مزامنة فكود الخروج 1)
```

## ممنوعات

- ❌ التعديل اليدوي على `core/src/main/kotlin/top/lhgb/ui/tokens/` (منتجات مولّدة، مُتجاهَلة في gitignore)
- ❌ إضافة ملفات الرموز المولّدة إلى المستودع
- ❌ كتابة قيم حرفية للألوان/المسافات داخل المكوّنات (مثل `Color(0xFF2B4C7C)` و`16.dp` و`14.sp`)
- ❌ كتابة شكل الاعتمادية `file:` / `link:` في `build.gradle.kts` وتنفيذها (الربط المحلي يقتصر على الجهاز المحلي)

## استكشاف الأخطاء

| العَرَض | السبب | الحل |
| --- | --- | --- |
| خطأ في البناء `unresolved reference: LhTokens` | الرموز غير مزامنة | `pnpm link:tokens` |
| قيم الرموز غير مطابقة للتوقعات | لم يُعاد توليد codegen في مستودع core | شغّل `pnpm codegen` في مستودع core ثم أعد الربط |
| `link:tokens` يبلغ عن «لم تُوجد منتجات الرموز» | المستودعات الشقيقة غير موجودة ولم تُثبّت حزمة npm | تحقق من تخطيط العائلة أو `pnpm i -D @lh-ui/core` |
| ألوان الوضع الداكن غير صحيحة | تم تغيير اللون الرئيسي الفاتح دون تحديث الحساب المسبق الداكن | حدّث `color-dark.json` وأعد التشغيل (R-n6) |
